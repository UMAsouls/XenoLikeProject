# 概要
戦闘終了はEnemiesSubsystemで検知する
EnemiesSubsystemは戦闘に参加しているEnemyを監視
全てのEnemyが戦闘から離脱した時点で戦闘が終了する
戦闘終了したらStateMachineがNormalStateに以降する

# 関連クラス
- EnemiesSubsystem
- BP_ThirdPersonGameMode
- BP_Enemy

# フロー
1. 戦闘開始
2. BP_Enemyが自分をSubsystemへ
3. 戦闘
4. BP_Enemyが倒される
5. 敵数のカウントが減る
6. 敵数のカウントが0
7. EnemiesSubsystemのデリゲート反応
8. BP_ThirdPersonGameModeがキャッチ
9. 戦闘終了処理
10. StateMachineをNormalStateに戻る
