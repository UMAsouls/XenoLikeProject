# 概要
戦闘終了はBattleSubsystemで検知する
EnemiesSubsystemは戦闘に参加しているEnemyを監視
全てのEnemyが戦闘から離脱した時点で戦闘が終了する
倒したor逃走はEnemiesSubsystemで判断
BattleSubsystemに戦闘勝利かただの終了か送信
戦闘終了したらStateMachineがNormalStateに以降する

# 関連クラス
- BattleSubsystem
- EnemiesSubsystem
- BP_ThirdPersonGameMode
- BP_Enemy

# フロー
1. 戦闘開始
2. BP_Enemyが自分をEnemiesSubsystemへ
3. 戦闘
4. BP_Enemyが倒されるor逃げる
5. 敵数のカウントが減る
6. 敵数のカウントが0
7. EnemiesSubsystemが勝利かどうか判定、BattleSubsystemに送信
8. EnemiesSubsystemのデリゲート反応
9. BP_ThirdPersonGameModeがキャッチ
10. 戦闘終了処理
11. StateMachineをNormalStateに戻る
